# Phase 5 Skill Mapping

Phase 5 的线上运行时不读取本机 Skill 目录；下列能力已转化为项目内的 Style Router、结构化 Schema、提示词约束和 TypeScript 校验。

| Skill | 项目内落点 |
| --- | --- |
| writing-dna-skill | `referenceText` → StyleProfile（句长、标点、情绪特征） |
| create-soul | Persona constraints（表达边界与禁用表达） |
| social-hook-writer | 3 类 Hook 与 5 类标题策略 |
| brand-voice-enforcement | `brandVoice` 检查与风格禁用项 |
| xhs-visual-director | `visualPlan`、封面方案与卡片层级 |
| guizang-social-card-skill | `socialCards` 的封面→痛点→内容→产品→CTA 结构 |
| content-angle-ranker | `angles` 的七维评分与推荐角度 |
| short-video-script-writer | `videoScript.scenes` 镜头级输出 |
| fact-check | 商品参数、无依据声明与风险校验 |

本页面是作品集 Demo：审核规则用于展示事实优先、可解释的工作流，不构成完整广告法或平台审核服务。
